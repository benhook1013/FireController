# FireController

FireController is a self-hosted coordination service for projects and their human and AI workers: jobs, durable messaging, review orchestration, and a live browser interface.

This repository contains the design, validation scaffold, and the first local CLI/profile commands. The service and browser runtime are not implemented yet. See [development](docs/development.md) for the implemented boundary, build commands, and private profile format.

Design and implementation changes are reviewed through pull requests with CodeRabbit. See [the design index](docs/README.md) for the AI-first scope, source evidence, decisions, onboarding, and acceptance scenarios.
