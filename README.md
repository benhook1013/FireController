# FireController

FireController is a self-hosted coordination service for projects and their human and AI workers: jobs, durable messaging, review orchestration, and a live browser interface.

The standalone rebuild is being designed. This repository does not yet provide a working replacement for the controller used by FireMUD. Its selected runtime and private state remain independent.

The initial design and implementation will be proposed through pull requests and reviewed with CodeRabbit.
