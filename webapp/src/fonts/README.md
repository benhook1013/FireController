# Header font

The masthead uses the Latin Inter semibold face at weight 600, distributed locally so browsers make no font-provider requests. Its private CSS family `FireController Header` keeps the selected title styling separate from body typography. Unsupported glyphs use the system sans fallback.

The unmodified font is the Google Fonts Inter 600 Latin WOFF2 used in the approved font comparison. The SIL Open Font License and copyright notice are distributed in [Inter-OFL.txt](../../public/fonts/Inter-OFL.txt), which the packaged site also serves at `/fonts/Inter-OFL.txt`.
